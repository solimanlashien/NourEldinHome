# Optimized GitHub upload ZIP parts

The site images were compressed for faster loading. Wood Carpentry card photos are compact WebP images sized for the cards. Other large raster images were recompressed and capped at 1600 pixels on the longest side. The project and product paths are preserved.

Extract all eight ZIP files into the same site folder. Every ZIP stores media under the shared images/ path, so they merge into one images folder. Part 01 also includes the site files at the root.

Each ZIP contains no more than 100 files:
- NourEldin_part01.zip — 82 files
- NourEldin_part02.zip — 100 files
- NourEldin_part03.zip — 100 files
- NourEldin_part04.zip — 90 files
- NourEldin_part05.zip — 99 files
- NourEldin_part06.zip — 96 files
- NourEldin_part07.zip — 82 files
- NourEldin_part08.zip — 80 files

Use the complete NourEldinHome-Optimized folder to preview the site. Upload the extracted files to GitHub; GitHub Pages does not unpack ZIP files automatically.
